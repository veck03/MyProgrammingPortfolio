# MyProgrammingPortfolio

## Simple Calculator

A tiny console calculator written in C++. It reads two numbers and an operator (+, -, *, /) from the user and prints the result. The implementation is in `main.cpp`.

## Run Instructions (Windows / PowerShell)

Using g++ (MinGW or MSYS2):

```powershell
g++ -o main.exe main.cpp
.\main.exe
```

Using Microsoft Visual C++ (Developer Command Prompt or PowerShell with Visual Studio environment):

```powershell
cl /EHsc main.cpp
.\main.exe
```
